# The Fourth Protocol

## Project Structure

### Folders
- `.vs/` — Visual Studio files for IDE configuration
- `ASSETS/` — Game assets like images, sounds, etc.
- `docs/` — Documentation files generated by Doxygen

### Key Source Files

- `AIPlayer.cpp` / `AIPlayer.h` 
- `Board.h`
- `Game.cpp` / `Game.h`
- `HumanPlayer.cpp` / `HumanPlayer.h` 
- `MainMenu.cpp` / `MainMenu.h` 
- `Npc.h` 
- `Piece.h` 
- `Player.h` 
- `Constants.h` 

---

## How to Build

1. Open the `SFML 3 Template1.sln` file in Visual Studio.
2. Build the solution.
3. Run the executable.

---

## Notes

- The project uses SFML 3 for graphics and input.
- All game logic is implemented in the source files above.
- Documentation is available in the `docs` folder.
