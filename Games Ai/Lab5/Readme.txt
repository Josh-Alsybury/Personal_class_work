Flow Field Pathfinding - Extra Features

1. Multiple Agent System (up to 5 agents)
   - Each agent has unique colour
   - Right-click to add/remove agents
   - All agents follow the same flow field simultaneously

2. Visualization Modes (5 total)
   - Normal: Basic grid view
   - Cost Field: Shows step costs
   - Integration Field: Shows cumulative costs
   - Heat Map: Colour intensity visualization
   - Vector Field: Arrow display showing flow directions

CONTROLS:
---------
Left Mouse: Set goal tile
Right Mouse: Add/remove agent (max 5)
Middle Mouse: Toggle wall
Space: Toggle agent movement
Q: Cycle through view modes
Escape: Exit
